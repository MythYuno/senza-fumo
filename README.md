# Senza Fumo

Un piccolo tracker motivazionale in stile Pip-Boy per accompagnare il percorso senza sigarette.

## Funzioni

- Contatore del tempo senza fumare.
- Stima del denaro risparmiato e mappa delle tappe.
- Mascotte interattiva con battute e incoraggiamenti.
- Schermate STAT, MAP e SOS, ottimizzate per iPhone.
- Dati salvati localmente nel browser.

## Avvio

Apri `index.html` in un browser. Non richiede dipendenze o installazione.

Le impostazioni e i progressi vengono conservati nel browser del dispositivo tramite local storage.
